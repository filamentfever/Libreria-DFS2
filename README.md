# ✏️ Tienda de Lapicería y Papelería

Sitio web estático para una tienda de papelería, útiles escolares y artículos de oficina. Permite a los usuarios explorar novedades, consultar el catálogo completo de productos y visualizar el detalle de cada artículo.

---

## 📁 Estructura del Proyecto

```text
cod_tienda/
│
├── index.html              # Página principal (inicio y productos destacados)
├── catalogo.html           # Catálogo general de artículos
├── producto.html           # Vista detallada de producto individual
│
├── css/
│   ├── styles.css          # Estilos personalizados de la tienda
│   ├── bootstrap.min.css   # Framework Bootstrap 5
│   └── ...                 # Archivos auxiliares y utilidades CSS
│
├── js/
│   ├── bootstrap.bundle.min.js # Scripts de componentes interactivos
│   └── ...                     # Archivos auxiliares de JavaScript
│
└── img/
    ├── imagendestaca.jpg   # Banner / imagen principal del inicio
    ├── cuadernomiku.jpg    # Cuaderno temático
    ├── estuche.jpg         # Estuches y organizadores
    ├── gomadeborrar.jpg    # Gomas de borrar
    ├── hojascarta.jpg      # Resmas y papel tamaño carta
    ├── lapizmina.jpg       # Lápices grafito / portaminas
